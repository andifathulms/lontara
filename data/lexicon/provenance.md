# Provenans leksikon / Lexicon provenance

**1,323 entries, every one of them `attestation: "corpus"` and `band: "unknown"`.
Regenerate with `pnpm lexicon:extract`.**

Invariant 13: every lexicon entry has a provenance field. No entry without a
source. Anything with unclear licensing does not go in, however convenient.

## What an entry actually claims

> This form occurs in Bugis Wikipedia article text, in at least two distinct
> articles that were not generated by a bot.

That is all. **It does not claim the form is a Bugis word**, and the difference
is not academic — the corpus contains Indonesian (`sekitar`, `adalah`,
`selatan`), English (`of`), and Vietnamese place names (`binh`, `quang`)
alongside genuine Bugis (`wanua`, `sibawa`, `mappunnai`, `éngka`, `laleng`).
Nothing in this repository can tell them apart. Doing so requires a dictionary,
which is the thing a lexicon is supposed to be.

So the weakness is carried in the data rather than hidden:

- every entry is `attestation: "corpus"`, the weakest of the three levels;
- `rank.ts` scores a corpus attestation at 2 against 30 for a dictionary and 60
  for a reviewer, so it can never look authoritative;
- the reader badges each such reading in `sabbe` and prints a warning above the
  tree;
- `pnpm lexicon:validate` says so on every run.

## Why there are no frequency bands

Every entry is `band: "unknown"`, and `lexicon:validate` **fails the build** if
a corpus-attested entry claims otherwise.

| | |
|---|---|
| Articles in the dump (ns 0) | 16,376 |
| Bot-generated French commune stubs | 13,911 (85%) |
| A second bot set repeating one image-caption legend verbatim | 618 |
| **Real articles remaining** | **836** |
| Tokens counted in those | 20,800 |
| Distinct forms | 6,756 |
| Forms in ≥2 articles | 1,383 |

A frequency band computed over that dump would describe a bot template, not the
language: before de-botting, nine "common Bugis words" each appeared in exactly
617–620 articles, because they are the colour key of one repeated map caption.

A band is a claim about frequency. This corpus cannot support one, so none is
made.

## Licence and attribution

- **Source:** Bugis Wikipedia (`bug.wikipedia.org`), dated
  `bugwiki-20260701-pages-articles` dump. Never `latest` — a citation pointing
  at a moving target is not a citation. The URL and sha256 are recorded in
  `entries.json` and verified by `scripts/corpus-fetch.mjs` on every fetch.
- **Licence:** CC BY-SA 4.0.
- **Attribution:** Bugis Wikipedia contributors. Each entry's `locator` names
  the articles the form was found in.

A frequency-filtered word list is arguably not a derivative work at all — a list
of forms with counts is closer to a set of facts than to expression. Attribution
is recorded regardless, because the cost of doing so is nothing and the cost of
being wrong about it is somebody's licence.

The dump itself is **not vendored**. It is fetched into `.corpus/` (gitignored)
and checksum-verified, which is the same reproducibility guarantee at none of the
repository weight.

## How extraction works

`scripts/lexicon-extract-bugwiki.ts`. In order:

1. Article namespace only.
2. Drop every bot-generated article (the filter regex is recorded in
   `entries.json` under `source.botArticleFilter`).
3. Strip wikitext: templates, tables, refs, media and category links, HTML,
   entities, list and table rows. Media links are stripped with a loop rather
   than one regex, because their captions nest `[[…]]` — which is how `jmpl` and
   `px` leaked into an early pass.
4. Tokenise on `[a-zé']+`, lower-cased.
5. **Strip leading apostrophes only.** A *trailing* apostrophe is the glottal
   stop — `salo'`, `aru'`, `ade'`, `baiccu'` — and stripping it would silently
   destroy an entire ambiguity class. Runs of two or more apostrophes are
   italic/bold markup and are removed before tokenising, so a surviving single
   apostrophe is genuine.
6. Require ≥2 distinct articles, which drops one-off typos.
7. Drop a small stoplist of markup remnants (`br`, `px`, `jmpl`, `katagori`…).
   It contains **only** tokens that cannot be a Bugis word. It is not a stoplist
   for foreign words: deciding which words are Bugis is precisely what this repo
   cannot do yet.
8. Require the form to be writable by the rule set with no unhandled input. An
   entry the writer cannot produce could never be reached by the reader's
   enumeration, so it would sit in the lexicon looking like coverage.

## Required fields per entry

```json
{
  "id": "bugwiki-20260701-wanua",
  "latin": "wanua",
  "band": "unknown",
  "attestation": "corpus | dictionary | reviewer",
  "provenance": {
    "source": "…",
    "locator": "68 article(s), e.g. …",
    "licence": "CC BY-SA 4.0",
    "licenceUrl": "https://…",
    "retrieved": "2026-07-01"
  }
}
```

`gloss` is optional and is **for reviewer verification only**. It is never
rendered anywhere in the UI, and `tests/invariants.test.ts` asserts it cannot
leak into an enumeration result. Transliteration is not translation
(invariant 16).

## What would actually improve this

A dictionary. `attestation: "dictionary"` is the point of that field existing.

| Source | Licence status | Action needed |
|---|---|---|
| Said, *Kamus Bahasa Bugis-Indonesia* (1977), via oxis.org | **Unverified.** Hosted as a downloadable PDF; hosting is not a licence. | Establish the copyright position before extracting a single entry. 1977 is not obviously out of copyright in Indonesia. |
| *Kamus Bahasa Bugis-Indonesia* (227 pp.), Wikimedia Commons | **Check the file's licence tag.** Commons hosting means a tag exists; it does not mean it is permissive. | Read the tag on that specific file and record it per entry. |
| *Kamus Dwibahasa Bugis-Indonesia* (2017), Wikimedia Commons | **Check the file's licence tag.** A 2017 work is very likely still in copyright. | Same. |
| Bugis–English–Indonesian dictionary ordered by **Latin** alphabet | **Unverified.** | Easiest to extract — prefer it for bulk work once the licence is settled. |

A dictionary would also let the corpus entries be *filtered* rather than merely
badged: any form not in the dictionary could be dropped or demoted, which is
what removes the Indonesian and the French place names.
